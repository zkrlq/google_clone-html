# 🔎 Google Clone

Clone básico da interface do Google desenvolvido utilizando **HTML**, **CSS** e **JavaScript**.

O projeto simula a página principal do Google e possui sistema funcional de pesquisa, permitindo realizar buscas reais diretamente pelo navegador.

---

# 📌 Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

# 🧠 Como Funciona

O usuário:

1. Digita algo no campo de pesquisa
2. Clica no botão de pesquisar
3. O JavaScript captura o texto digitado
4. O navegador redireciona automaticamente para a busca

---

# ⚙️ Funcionamento da Pesquisa

O sistema utiliza JavaScript para montar a URL da pesquisa:

```javascript id="24yk8a"
window.location.href
```

permitindo abrir os resultados diretamente no navegador.
